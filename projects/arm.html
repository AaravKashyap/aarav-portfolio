Tendon-Driven Robotic Hand

A from-scratch build of a paracord-tendon robotic hand — CAD assembly, custom parts, servo wiring, and two working control schemes: keyboard, and real-time webcam hand-tracking.

Fusion 360ArduinoPythonMediaPipePCA9685
Fingers
4 + opposable thumb
Actuators
5× MG995 + 1 micro servo
Driver
PCA9685 + Arduino Uno
Tendons
Paracord + fishing-line return

Overview

This hand started from a set of 9 raw STL files based on Robert Gross's open-source "Humanoid Robotic Hand" design, originally published on Thingiverse. Getting from those files to a working hand meant assembling everything in Fusion 360 with correct joints, then designing several fully custom parts — including a flat-base standing end cap and a reverse-engineered "star-style" servo horn matched to real MG995 hardware, since the original horn design didn't fit the servos actually available.

Four fingers plus an offset, angled thumb are driven by paracord tendons routed through channels in each phalange, pulled by servo-driven winches mounted in the forearm, with fishing line handling the return pull as each servo relaxes. The whole hand also rotates at the base.

Electronics

Six servos in total — five MG995 metal-gear servos for wrist rotation and the four main fingers, plus one micro servo dedicated to rotating the thumb sideways — are driven through a PCA9685 driver board talking to an Arduino Uno R3 over I2C. Each joint has a fixed channel on the board:

  • Channel 0 — base rotation (wrist)
  • Channel 2 — index finger
  • Channel 4 — ring + pinky fingers (ganged together)
  • Channel 6 — thumb main curl
  • Channel 8 — middle finger
  • Channel 10 — thumb sideways (micro servo)

Control: keyboard

The first working control scheme pairs an Arduino sketch with a Python script running on the computer. The Arduino listens for single-character commands over serial and nudges the matching servo channel; the Python side watches the keyboard and streams commands continuously while a key is held, since the Arduino IDE's own Serial Monitor only sends one character per keypress.

  • Q / W — base rotation
  • A / S — index finger
  • Z / X — ring + pinky
  • E / R — thumb curl
  • D / F — middle finger
  • C / V — thumb sideways
  • Space — center every joint

Control: webcam hand-tracking

The more ambitious goal was to skip the keyboard entirely and have the hand mimic my actual hand through a webcam in real time. Getting there took three attempts. Native Python with MediaPipe kept crashing on startup with a Metal/GPU delegate failure that turned out to be tied to how MediaPipe's native build interacts with Apple Silicon. Switching to Ultralytics YOLO's pose model avoided the crash, but pose models only track whole-body keypoints — shoulders, elbows, wrists — with no concept of individual fingers, so it couldn't actually drive finger motion.

The fix was moving MediaPipe into the browser. MediaPipe ships a JavaScript build that runs via WebAssembly, sidestepping the native crash entirely, and Chrome's Web Serial API can talk to the Arduino directly from a webpage with no Python needed at all. The final setup is a single HTML file: it reads all 21 landmarks per hand from the webcam feed, computes a curl value for each finger from landmark geometry, maps that curl to a servo position, and streams it straight to the Arduino — mirroring my hand's finger curls and wrist position onto the robotic hand live.
